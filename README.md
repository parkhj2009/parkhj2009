## 대표 작업

### 01 · 필요한 정보를 홈 화면에서

급식과 시간표를 확인하는 Android 위젯을 만들었습니다. 위젯 크기에 따라 내용을 배치하고, 데이터 갱신과 테마, 미리보기까지 연결했습니다.

`Kotlin`　`Jetpack Glance`　`Android Widgets`

[위젯 개발 PR 보기 ↗](https://github.com/Team-B1ND/dodamdodam-app/pull/70)

### 02 · 팀으로 신청하는 심야자습

팀 선택 바텀시트와 팀원 목록을 신청 화면에 연결했습니다. 팀에 포함된 학생의 중복 선택을 막고, 작은 화면에서도 신청 흐름을 따라갈 수 있도록 개선했습니다.

`React Native`　`TypeScript`　`React Hooks`

[팀 선택 기능 ↗](https://github.com/Team-B1ND/dodamdodam-app/pull/52)　·　[신청 화면 개선 ↗](https://github.com/Team-B1ND/dodamdodam-app/pull/61)

### 03 · 운영을 위한 웹 화면

프로젝트 심야자습 관리 화면과 상세 다이얼로그를 만들고, 팀·학생 정보를 불러오는 데이터 흐름을 연결했습니다.

`React`　`TypeScript`　`Vite`　`CSS`

[관리 화면 PR 보기 ↗](https://github.com/Team-B1ND/dodam-aid-nightstudy/pull/6)
